AGENT TOOLS — HEIC and subtitle input recovery


## Troubleshooting: fix the input before retrying
The run's key-value store may contain an `ERROR` record with an `error.code`.
- `INVALID_BASE64`: send raw, standard base64 of the original file bytes. Remove a `data:image/heic;base64,` prefix; do not send a filename, URL or the bytes decoded as text. Do not change arbitrary characters to make validation pass.
- `EXPECTED_IMAGE_BASE64_ONLY`: send exactly one JSON field, `imageBase64`.
- `INPUT_TOO_LARGE` or `PIXEL_LIMIT`: use an input within the 10,000,000-byte and 16,000,000-pixel limits. Resizing the output cannot bypass the input decoder limit.
- `MULTIPLE_IMAGES` or `UNSUPPORTED_HDR`: this version cannot process that image variant. Export a supported single-image, 8-bit file with your existing image tool; repeatedly submitting the same input will not help.
- `INVALID_OR_UNSUPPORTED_HEIC` or `UNSUPPORTED_ICC_PROFILE`: use another supported export or a local converter. Do not assume every HEIC from a particular device is supported.

If your HTTP request times out, first inspect the existing Apify run and its output. A timeout does not prove that conversion failed. Do not automatically start another run: this can duplicate processing and charges. A rejected input has no successful-conversion event; this is different from a successful run whose HTTP response was lost. Never publish source images, tokens or private output in support issues.


## Troubleshooting: fix the input before retrying
The run's key-value store may contain an `ERROR` record with an `error.code`.
- `NON_POSITIVE_DURATION`: a cue ends at or before its start. Correct the source timing; the parser does not guess a replacement duration.
- `MISSING_WEBVTT_HEADER` or `MISSING_HEADER_SEPARATOR`: for WebVTT, include the `WEBVTT` header and its blank-line separator. Setting `format` to `vtt` does not convert SRT syntax.
- `MISSING_SRT_INDEX` or `INVALID_SRT_INDEX`: strict SRT requires a numeric identifier before each timing line.
- `AMBIGUOUS_CUE_SEPARATOR`: separate cues with a blank line; do not place another timing line inside a cue's dialogue.
- `INVALID_CHUNK_SIZE`: use an integer from 100 to 8000. This is a soft character target, not a token budget.

Example of a valid strict SRT cue:
```text
1
00:00:01,000 --> 00:00:03,000
A complete sentence.
```

If your HTTP request times out, inspect the existing Apify run and its dataset before retrying. A lost response may hide a successful, charged run. Automatic replacement runs can duplicate processing. A rejected file has no successful-parsing event; review its error and fix the input first. Use only synthetic, redacted excerpts when asking for support.
